Lumen Drift is a neon arena survival shooter set in a drifting starfield. You pilot the last Wisp, dodge and outgun hostile Drifters, and survive eight escalating waves before the Maw breaks the final silence.

Controls: WASD or arrow keys move; the mouse aims; hold the mouse button or press Space to fire; P or Esc pauses; M mutes. Press Enter or click to begin, and on the end screen press R or Enter to restart.

## Run it

```bash
node serve.ts
```

Then open http://localhost:8080 in a browser.

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the entry bundle to `out/`.
